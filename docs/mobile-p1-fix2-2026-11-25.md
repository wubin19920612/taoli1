# 手机 P1 修复 2（真机核对，2026-11-25）

基于 `codex/mobile-p1` @ edfb574（= 生产）。只改 `backend/app/models/mobile.py`、`backend/app/services/mobile_summary.py`、`backend/app/api/routes_mobile.py` 及对应测试。字段只**新增**，不删除、不改名（旧版 App 仍在用）。

1. **卡片 id**：`MobileCard` 新增 `id: str | None`（Astro 原始 `id`）。
2. **按 id 查历史**：新增 `GET /api/mobile/cards/by-id/{card_id}/history?hours=`，返回同 `CardHistory`；找不到 404。旧的按名称接口保留不变。复用同一套历史服务与只读会话白名单（`/api/mobile/*` 已覆盖）。
3. **自动开/清标记**：新增 `open_auto: bool`、`close_auto: bool`。条件为 None 或 `abs(condition) >= 100`（百分比单位，即 Astro 原始 FF 值 ≥ 1 或 ∞）时为 false。为 false 时对应 `gap_to_open` / `gap_to_close` 置 None。
4. **单腿/不平衡持仓**：新增 `leg_a_notional`、`leg_b_notional`（数量绝对值 × 开仓均价，缺均价时 None）和 `leg_imbalance: bool`：持仓中且（某一腿数量为 0，或两腿名义值都有且 `abs(a-b)/max(a,b) > 0.2`）。
5. **排序**：在现有规则之前先按状态分组：① `leg_imbalance` 为真；② 持仓卡；③ `state != "paused"` 的未持仓卡（按 gap_to_open 从大到小，None 最后）；④ 暂停的未持仓卡（同样排序）。
6. 测试：每条至少一个用例（含 OPENAI 样例：qty_a=0.059、qty_b=0 → leg_imbalance；openPosition="10"、closePosition="-10" → open_auto/close_auto=false 且 gap 为 None；Infinity → close_auto=false；按 id 查历史 200/404；排序）。
