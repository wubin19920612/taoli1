# 手机 P1 修复 1（审查结论，2026-11-24）

基于 `codex/mobile-p1` @ ebf131a。尚未部署，可直接改本分支已有提交的代码。审查原文：`output/mobile-p1-review.log`（主仓库 output 目录）。

1. **表名冲突（必修）**：现有 `alert_events` 是规则告警投递历史，**不得改名或改结构**。删除 `schema.py` 里 RENAME 迁移和 `alert_events_rule_history`，恢复 `alert_events` 原定义与所有原读写代码（`git diff a1d61da` 里涉及它的改动全部还原）。手机提醒用新表 `mobile_alert_events`（字段同原任务书 §4），仓库、清理、`/api/mobile/alerts` 全部改用新表。测试：旧库启动后 `alert_events` 结构与 a1d61da 完全一致。
2. **不能拖慢飞书（必修）**：三个发送入口改为**先发飞书、后记录**；记录用后台任务（保留任务引用防 GC，`asyncio.wait_for` 超时 1 秒，异常只记日志）。`send_alert` 在 webhook 未配置时的抛错行为与 a1d61da 一致（放回原位置）。测试：记录挂起 5 秒时发送耗时 < 0.2 秒；加急文本同样。
3. **脱敏补全（必修）**：增加 `passphrase`、`access[_-]?key`、`ok-access-*`、`x-mbx-apikey`、`sign(ature)?`、`private[_-]?key`、`cookie`、`set-cookie` 的键值隐藏；0x 开头 64 位十六进制私钥；测试覆盖每类。
4. **单卡异常不拖垮整体（必修）**：summary 中每张卡的处理包 try/except，出错时该卡 `metric_error="卡片数据格式异常"`，其余字段尽量填，整体仍 200；所有 `.upper()/.strip()` 等对非字符串安全。测试：`type=123`、`name=None`、数字字段为非法字符串。
5. **HL DEX 与网页一致（必修）**：DEX 未填时的匹配逻辑严格按前端 `astroMarket`（requestedDex = dex 为空时 "main"，marketDex 取 market.dex 或 raw_symbol 前缀，HL 无前缀为 "main"；只取 data_status=="live"；有 markets 但无精确匹配 → 缺行情，不回退）。补一个与网页口径对照的夹具，手机必须和网页同样显示缺行情。
6. **历史接口同名卡**：`/api/mobile/cards/{name}/history` 加可选 `type` 查询参数；summary 每卡输出 `type`（已有）。同名多张且未给 type 时 409 并在 detail 里列出可选 type。
7. 不修：nginx 静态页（数据接口已拦）、WebSocket（当前无路由）、funding_diff 直接相减（与 Astro 卡片口径一致，App 会同时显示两边周期）、跨 dex 重复筛选（性能已达标）。

验收：新增/修改测试通过；`cd backend && python -m pytest -q`（Windows 用去掉 uvloop 的锁定依赖，`--basetemp` 指到工作树内 `.pytest-tmp`，并加到 .git/info/exclude）贴汇总行；`git diff --name-only a1d61da` 中 `schema.py` 只剩新增 `mobile_alert_events` 和会话 scope 相关；提交 `fix(mobile): ...`。不要 push、部署、跑 WSL。
