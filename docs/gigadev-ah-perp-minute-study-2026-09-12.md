# 兆易创新 A/H 与永续价差分钟研究（2026-09-12）

## 结论

最近可用数据不支持“确定性套利”。它支持两个更有限的结论：

1. A/H 同时交易时，两张永续能较好跟随各自现货，永续 A/H 价差减现货 A/H 价差的分钟残差大多在正负 0.5 个百分点内。
2. 现货休市后残差存在约 -1 个百分点的偏移，但只交易两张永续并不能锁住这个残差。次日 A/H 现货价差本身会跳变，最近有效的隔夜样本有赢有亏。

## 标的映射纠正

- A 股：`603986.SS`，人民币计价。
- H 股：`3986.HK`，港币计价。
- Hyperliquid：`xyz:GIGADEV`，逐分钟价格与 A 股折美元价格吻合。
- Binance：`GIGADEVUSDT`，跟踪 H 股，不是 A 股。

Binance 的公开 `exchangeInfo` 明确给出 `underlyingType=HK_EQUITY`；公开指数成分接口明确给出 `3986HKD` 和 `3986HK`。严格同分钟样本中，Hyper 对 A 股的平均绝对跟踪误差为 0.173%，对 H 股则为 6.475%；Binance 对 H 股为 0.293%，对 A 股则为 7.220%。

因此，两组可比价差必须统一为 A 相对 H 的方向：

```text
现货对称价差 = (A股美元价 - H股美元价) / 两者均价
永续对称价差 = (Hyper价格 - Binance价格) / 两者均价
残差 D = 永续对称价差 - 现货对称价差
```

这与项目页面的对称价差口径一致。脚本也输出传统 `A/H - 1` 比率口径，便于交叉检查。

- D 均值 -0.073pp，标准差 0.374pp，P5/P95 为 -0.721/+0.510pp。
- 83.0% 的分钟满足 `|D| <= 0.5pp`，98.3% 满足 `|D| <= 1.0pp`。

## 策略含义

目前最接近可研究信号的是：现货休市后 `D` 显著低于同盘基线时，观察是否存在次日开盘回归。但最近样本无法确定阈值：`D <= -1pp` 的可结算历史事件也只有极少数，并且已有亏损。

在获得至少 20 至 60 个独立交易日之前，不应启用无条件自动交易。继续验证时应：

1. 用实时 bid/ask 而不是分钟 close 生成可成交价差。
2. 记录 Hyper 每档深度和目标下单量的冲击成本。
3. 以独立交易日统计胜率，不能把高度自相关的分钟数当样本量。
4. 分离 A/H 现货锚变化和永续相对现货残差变化。
5. 排除公告、停牌、涨跌停、节假日错位和上市初期价格发现阶段。
