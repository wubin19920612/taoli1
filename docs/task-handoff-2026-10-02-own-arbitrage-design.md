## 业务与安全规则

- 第一版一个核验后的订单簿 DEX+CEX、1–3 标的，线性同标的 SF/FF，已有现货库存；限价 IOC 小切片、默认顺序腿，额外验收后可启用受保护并行 IOC。其他协议/借币/统计比率/自动调资后续独立验收。
- 任何执行判断必须说明资金费周期、双方成交额、实际盘口、费用来源、原始市场/DEX、合约乘数与估算标志。
- 结果未知不当失败，不换 ID 盲重试，不因 not-found 立即释放预算；最终风险计入所有在途余量。
- 补腿/应急退出同时评估组合与在途风险；reduce-only 不等于组合风险一定降低。
- 启动/恢复先对账，账本不可写禁开，未知仓位隔离。第一版无跨主机自动 failover，禁止旧实例继续发送。
- 不把 Astro 字节码接入生产依赖，不运行未隔离的 .jsc，不用 Node vm 当安全沙箱，不记录秘密。
