# crossex-exec 第七轮（待第六轮完成后执行）：两腿盘口同时性（2026-11-11）

用户已确认。依据：fill-sim 300 档收敛单两腿盘口交易所时间差中位 0.62s、p90 1.11s、最大 2.3s，小币 5 秒波动约 20bp，时间差可拼出假价差。

## 要做的
- 开仓复核（含共享发送前复核）新增条件，全部满足才放行：
  1. 两腿盘口的**交易所时间戳**之差 ≤ 300ms（交易所不给时间戳的，用收到时间，并在交接里列出是哪些所）；
  2. 每腿盘口年龄（now − 交易所时间戳，或收到时间）≤ 1.0s（原为 2s）；
  3. 不满足时立即并发重拉一次两腿盘口再判一次，仍不满足就放弃本次机会，记原因 `book_skew` 或 `book_stale`。
- 平仓判定不加这条限制（平仓必须能执行），但平仓记录里写入两腿时间差，供对比。
- 参数写成常量，可配置调严，不能调松。
- `/api/v1/trades` 和 positions 增加 `open_book_skew_ms`、`close_book_skew_ms`；summary 增加 `book_skew` / `book_stale` 放弃次数。契约文档同步。

## 测试
- 时间差 301ms 拒绝、300ms 放行；年龄 1.01s 拒绝；重拉一次后满足则放行；两次都不满足则放弃且不发单。
- 不变量模拟器 3 种子各 ≥2400 回合全过；两条 unittest 全过。

## 追加（用户 2026-11-11）：v1 只做“乌龙指”型价差
用户判断：资金费差≈0、纯粹由某一家瞬间报价异常（乌龙指）造成的价差风险最小；带资金费差的价差复杂得多，v1 不做。开仓在第六轮条件之外，再全部满足：
1. **无资金费差**：两腿每小时资金费率之差的绝对值 ≤ 0.5bp/h（2 小时 ≤1bp）；且每腿资金费率绝对值折合 8 小时 ≤ 0.05%。读不到任一腿则不开。
2. **常态价差接近 0**：该交易对 `|baseline_bps| ≤ 10`，且 MAD ≤ 10bp（比第六轮的 80/40 更严）。
3. **是“一家异常”而不是“整体在动”**：该币至少在 3 家（白名单 6 家内）有行情；用基准模块最新一轮各所中间价求中位数 M（不含两腿本身时至少还要 1 家参考），要求：异常腿偏离 M 的幅度 ≥ 开仓超额的 70%，另一腿偏离 M ≤ 10bp。方向必须是“买入被砸低的那家 / 卖出被拉高的那家”。
4. 放弃原因分别记：`funding_diff`、`baseline_not_flat`、`not_single_venue_outlier`、`too_few_venues`。summary 统计各原因次数。
以上阈值写成常量，可配置调严，不能调松。测试：每条边界各一组；不变量模拟器 3 种子各 ≥2400 回合全过。
