- 自动链路只读取 Astro 列表和新增停用卡片，不更新已有卡片，不调用外部消息、交易、借币或杠杆端点。建卡前重新采样、核对身份版本、配置代次、全局过滤条件与有效期。每轮最多一次新增写入；Astro 的 add 可能重启其 core，沿用已有 SDK 行为。

## 范围与验收

第一版监测 Bybit USDT 线性永续多头 + 同平台借币现货空头；仅查询，不借款、不下单、不修改交易账户模式。不接 Astro 自动建卡。Binance、其他平台及跨平台路线属于后续适配。

负费率市场全量初筛，按每小时费率排序，对有限候选深查。页面区分产品支持、账户可借额度、可用库存、成本通过，缺失信息不当作零。账户信息、配置、快照与事件接口均要求非空仪表盘密码。复用加密账户连接，仅显式选中的 Bybit 账户参与查询。

## 数据与可信边界

- 公开：`/v5/market/instruments-info`（线性分页）、`/v5/market/tickers`、`/v5/market/orderbook`、`/v5/spot-margin-trade/data`。
- 签名 GET 白名单：`/v5/spot-margin-trade/state`、`/v5/account/collateral-info`、`/v5/spot-margin-trade/max-borrowable`、`/v5/spot-margin-trade/flexible-available-inventory`、`/v5/account/fee-rate`。
- `maxBorrowingAmount` 只是公开档位上限；不替代账户额度或库存。库存接口本身为多个限制的最小值。账户错误只输出分类，不返回原始异常、签名或请求头。
- 双腿保留原始市场、USDT 报价、周期、下一结算时间、各自成交额、来源时间。第一版只接受同 base、同 raw symbol 的普通 1:1 USDT 线性合约；倍率品种不静默归一化。已有资产核验记录必须有效且双方相同；用新拉盘口重验，不使用 ticker 同名自动确认身份。
- 时间过期、跨腿时间差、未来时间、异常数值、缺少元数据/费率/深度，均阻断成本通过。未知不等于不可借。账户额度查询不锁定库存，也不证明两腿下单保证金足够。

## 收益与容量

目标金额以现货卖出参考价换成基础币数量，按两腿数量步长的最小公倍数向下取整；检查最小数量、最小金额、最大市价数量。四侧订单簿以同一个 q 计算 VWAP，深度不足不外推。

`净收益 = -q * 永续标记价 * 预估资金费率 * 结算次数 - 借币利息回购成本 - 四笔手续费 + q*(现货开卖均价-永续开买均价-现货回买均价+永续平卖均价) - 额外执行缓冲`。

分别计算下一结算（留出两分钟退出余量）、设置持有期、24小时。结算次数按下一结算时点计数，不能用持有小时/周期作为到账次数。当前费率、利率、标记价与退出盘口均是假设不变的情景估算，不承诺基差收敛。利息采用向上取整小时的保守预算，并明确不是交易所账单；另预留一小时首期扣息库存余量。压力情景另扣配置的基差恶化幅度。公开手续费为可修改假设，账户费率可查询成功后覆盖；假设费率不升格为成本已核验。

## 运行、留存与界面

独立异步任务默认每60秒扫描，单轮50秒超时；默认深查15条，最多30条，并发3条、请求间隔至少120ms。目录元数据缓存一小时，入选候选再次查询双腿当前规格/状态；资金周期取实时 ticker，不能依赖缓存目录周期。刷新请求仅排队，不等待整个扫描；单飞避免重入。独立 SQLite 连接使用主库，包含在现有备份内。每五分钟保留一份快照、最多288份；状态变化事件最多500条。保存的是来源、利率、库存、四侧均价及估算，不保存账户密钥。

盘口有效窗口最多30秒，其他行情/账户来源60秒，已核验配对还受既有15秒复核有效期限制；因此两轮采样之间可能显示上一快照过期，这是采样观察池，不是持续可执行报价。当前页面每5秒读取已有结果，不触发交易所请求。配置或账户变更立即使旧结果失效，运行中的旧配置扫描不能覆盖新配置结果。

站内事件记录发现候选、额度满足、成本通过及条件失效，不自动发送外部消息。结果过期时页面/API降级，不展示旧的通过状态。页面展示账户选择、金额/周期/门槛配置、候选表、详细成本、来源、历史快照与事件。
